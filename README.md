# Contact Me Freely — Developer Portfolio

A personal portfolio website for Gebremedhn Sisay. The project introduces the developer, describes current learning goals, and provides a starting point for showcasing completed work.

## Features

- Responsive layout for desktop and mobile screens
- Semantic HTML sections and skip-to-content link
- Keyboard-visible focus styles and reduced-motion support
- Mobile navigation with an accessible expanded state
- Skills and project sections
- Links to the source repository and GitHub profile

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone the repository:
   `git clone https://github.com/yosefsisay18-byte/contact-me-freely.git`
2. Open the project folder.
3. Open `index.html` in a modern browser. No build step is required.
